# Latourette-Fiscal Co. v. Hanify

## Majority (THE COURT.)

THE COURT.
The above consolidated cases arise out of the same transaction set forth in consolidated cases No. 4598, Globe Indemnity Co. v. Hanify, ante, p. 721 [20 Pac. (2d) 689], this day decided, and, therefore, come within the rule announced therein. Each judgment appealed from herein is affirmed upon the grounds and for the reasons set out in said consolidated eases No. 4598.
It is so ordered.
Rehearing denied.
